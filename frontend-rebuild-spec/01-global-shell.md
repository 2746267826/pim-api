# 01 全局框架（Global Shell）

## 1. 应用形态

- **单页应用（SPA）**：React 19 + TypeScript + Vite；路由 react-router v7（BrowserRouter）；数据层 TanStack Query v5（唯一缓存层）；UI 语言 zh-CN。
- **部署形态**：构建产物输出到后端 API 的静态目录，由 API 同源伺服（生产环境 SPA 与 API 同源；开发环境由 Vite 开发服务器代理 `/api` → `http://localhost:5858`）。前端不需要独立部署的后端。
- **依赖的关键能力型组件库**（重建时需要等价能力，不限定同款）：完整日历网格（月/周视图、拖选时间段、外部拖入）、图表引擎（折线/柱状/环形/漏斗/仪表盘/自定义热力矩阵）、地图引擎（瓦片底图 + 折线轨迹 + 圆形覆盖物 + 自定义标记）、富文本/Markdown 编辑器、上传队列、树控件、图片灯箱、Toast 通知。

## 2. 顶层布局结构

```
┌──────────────────────────────────────────────┐
│ 侧边栏（桌面常驻；移动端折叠为汉堡+抽屉）        │
│  ① 一级导航 16 项（见 §3）                     │
│  ② 日历本管理器（CRUD+显隐）                    │
│  ③ 任务本只读列表（点击跳任务页）               │
│  ④ 系统状态指示点（链接到 /status）             │
│  ⑤ 用户名 + 版本 + 登出                        │
├──────────────────────────────────────────────┤
│ 主内容区（每页独立 ErrorBoundary + 加载占位）   │
│ （日历页右侧额外停靠"收件箱侧板"，见 §5）        │
├──────────────────────────────────────────────┤
│ 页脚：本地版本 / API 版本 / "有可用更新"标记     │
└──────────────────────────────────────────────┘
全局浮层：快捷记录 FAB（除 /quick-notes 外所有页）
全局 Toast 通知（API 错误统一上浮、去重）
```

- **移动端适配**：侧边栏折叠为顶部汉堡按钮 + 背景遮罩抽屉；每页有移动版页头（标题+返回/操作）；宽表格在窄屏降级为卡片列表；三栏文件页在窄屏改为"树抽屉 + 全屏预览"；编辑面板在窄屏变为右侧抽屉。

## 5. 全局浮层模块

| 模块 | 出现范围 | 形式 | 调用接口 | 处理 |
|---|---|---|---|---|
| 快捷记录 FAB | 除 `/quick-notes` 外所有页 | 圆形悬浮按钮 → 弹出菜单（写闪念 / 建任务→任务页 / 排日程→日历页）；"写闪念"打开可拖拽的闪念编辑弹窗 | 闪念域接口（见 02 §quick-notes） | 弹窗位置记忆在 localStorage；编辑器支持粘贴/上传图片附件 |
| 收件箱侧板 | 仅 `/calendar` | 右侧停靠任务卡片列表：未排期/收件箱任务，优先级点+截止日；顶部"新建"菜单（任务/日程编辑弹窗）、"一键重排"按钮 | GET /api/v1/calendar/tasks（无参数，客户端过滤收件箱/未排期）、POST /api/v1/calendar/tasks/{id}/plan | 列表项为**拖拽源**：拖到日历时间槽触发排期（自动按时长估算）；标准轮询 |
| 全局 Toast | 所有页 | 轻提示堆栈 | — | 查询/变更失败统一上浮；5xx 在后台轮询或已有缓存数据时静音；按 key 去重 |

## 6. 认证流（形式级）

- **登录页**：单卡片表单，仅登录（用户名+密码）；账号由管理员创建（全新部署的引导见后端注册策略）；内联错误提示；成功后存令牌并回跳。
- **令牌机制**：访问令牌 + 刷新令牌存 localStorage（内嵌页例外：由原生桥注入、不落盘）；所有请求自动带 `Authorization: Bearer`；任意请求遇到首个 401 时自动调刷新接口（并发请求共享同一次刷新），失败则清令牌回登录页。详见 [04-api-conventions.md](04-api-conventions.md)。
- **登出**：纯客户端清令牌（无服务端调用），回登录页。

## 7. 错误/空/加载态（形式类别清单）

| 类别 | 形式 |
|---|---|
| 页面级错误 | 错误边界：错误页（提示 + 重试 + 回首页）；404 页 |
| 模块级错误 | 卡片级错误边界（模块内提示，不影响整页） |
| 全局 API 错误 | Toast（去重、5xx 静音规则） |
| 加载中 | 骨架占位块 / 加载指示；页面级 Suspense |
| 空状态 | 统一空状态组件（图标位+一句话+可选操作）；占位框式空提示 |
| 操作结果 | 操作结果横幅（成功/失败+详情链接）；内联告警横幅 |
| 破坏性操作确认 | 确认对话框：列出受影响数量+样例行；日历删除等高危操作要求输入确认；确认中心为"两步武装确认" |
