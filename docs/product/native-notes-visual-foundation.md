# PIM 视觉基础与笔记样板

版本：v0.3 安卓主题首批实施稿。日期：2026-10-25。

用户已同意“先薄视觉基础和关键页样板，随后立即进入真实功能”的方法，并明确延续 PIM 蓝色基调、取消常驻“PIM 笔记”品牌栏、将结束操作放在右上角悬浮，以及颜色和基础组件一处定义、多处引用。用户已确认外观足够，先统一后继续，不再扩展大批静态样板。其余细节在真实切片中完善，业务规则与稳定需求编号仍以 [PIM原生客户端与笔记路线图](native-notes-roadmap.md) 为准。

## 1. 设计原则

- 整个 PIM 共享产品识别与视觉语义，首先用笔记证明可用，不提前设计全部日历/任务等页面。
- 延续原生客户端已有蓝色方向，已获用户确认；正文阅读与书写优先，主操作不靠大面积色块抢占编辑区。
- 页首直接呈现笔记标题与保存状态，不再常驻“PIM 笔记”品牌栏；“结束”作为应用内右上角轻量悬浮操作，与标题留出避让空间，不另占整行。结束确认和后续补录规则不变，不是跨应用悬浮窗。
- 所有颜色从统一主题的语义资源引用；按钮、输入区、状态提示等基础组件只维护共同定义和必要变体，不在业务页面复制样式。
- 录音条保持应用内左下角紧凑悬浮；手写卡片内嵌正文，右下角直接拖动宽高。位置和交互是已确认规则，不参与本轮外观方案的重新投票。
- 状态用文字与结构表达，颜色仅辅助；录音、暂停、保存、上传、AI 完成、中断和冲突不得混淆。
- 手机、平板按实际可用空间重排，不按 OPPO 型号写死尺寸，不把平板当成放大的手机，也不把同一布局强行缩小。

## 2. 阅读布局参考

| 方向 | 排版与布局 | 交互差别 | 当前定位 |
| --- | --- | --- | --- |
| 清晰文档 | 蓝色克制强调、干净文档底色、无衬线标题、下划线内容导航；宽屏时左侧展示本篇录音/手写/照片材料 | 平板从材料侧栏直接进入对应内容；手机保留单列正文 | 保留布局对照，不据此继续扩大静态样板 |
| 安静纸面 | 同一蓝色产品识别，偏暖纸面、中式衬线标题、独立文档页、分段式内容导航；宽屏正文居中并增加页边距 | 材料入口收在原稿和插入操作中，结果按阅读稿组织，不常驻材料侧栏 | 最近样板偏好，作为阅读布局参考；不把所有字体和平台数值视为冻结 |

两者不是仅换颜色：页面结构、宽屏空间分配、材料访问方式、标题及内容导航均有差别。蓝色基调、取消品牌栏、右上角结束、左下角录音及手写拖拽行为共同生效，不再作为待确认项；不能把这些确认扩大为所有字体、主题范围和布局细节已冻结。

## 3. 薄视觉参数建议

以下是样板参数，不是已经写入 Compose/WPF/Web 的跨端主题。语义名称可共享，平台数值及资源实现分别维护。

| 语义 | 浅色建议（清晰文档） | 深色建议（清晰文档） |
| --- | --- | --- |
| 页面背景 | `#F7F9FC` | `#121A29` |
| 文档/菜单表面 | `#FFFFFF` | `#1C2738` |
| 正文 | `#14243B` | `#E8EEF8` |
| 次要文字 | `#506176` | `#B4C0D2` |
| 品牌/交互 | `#1D63D8` | `#93B7FF` |
| 品牌按钮文字 | `#FFFFFF` | `#0B2149` |
| 细边界 | `#D9E1ED` | `#354256` |
| 正常保存 | `#1C6C50` | `#8BD3B0` |
| 需注意/过期 | `#8A540D` | `#F2C37F` |
| 中断/失败 | `#B42332` | `#FFADB4` |

- 中文正文起步 16、舒适行距；样板提供 16-20 像素阅读检查。原生使用平台文字单位、系统字号缩放与实际字体回退，不把浏览器像素当作 Android sp/dp。
- 标题约 24-25，节标题约 19，辅助信息约 12；正文不因平板空间变多而无限加宽或字号变小。候选衬线字体仅影响标题，正文保留易读的中文无衬线。
- 间距优先 4/8/12/16/24/32 等少量层级；正文初始内边距沿用先前草图中的 12，平板可增加页边距；拖拽尺寸不是间距档位，不限制为预设大小。
- 边框细、层级浅；只为浮条、弹出菜单和必要选中态使用轻量阴影，不把每个正文段落都包装成卡片。
- 原生触控优先遵循 Android 约 48 dp 等平台规范；样板按钮以至少约 44 像素可点区域检查，不能将其当真机输入验收。
- 深浅样板检查不等于现有全应用已经支持暗色。最终主题交付范围、字体资源/授权与无障碍需进入真实客户端核验。

### 3.1 一处定义、多处引用的实现约束

- 主题入口集中定义颜色资源，业务页面只引用 `Primary`、`OnPrimary`、`Surface`、`Text`、`TextMuted`、`Border`、`Success`、`Warning`、`Error` 等语义，不直接散写色号。浅深色映射集中维护，不能靠逐页替换蓝色色号调整产品基调。
- 字体层级、常用间距、圆角、触控目标和浮层阴影使用命名资源；按钮、图标按钮、输入区、材料边界、状态提示和确认框共享基础定义及明确变体。页面负责组合和行为，不复制一份控件再单独调样式。
- 样板已将颜色集中在根级主题资源中，通过引用供两种布局使用；基础按钮、输入区和材料边界使用共同样式，浮动结束按钮复用主按钮而非另造一套。用户拖出的卡片尺寸、波形样本和按空间计算的布局是运行数据，不要因此变成固定尺寸档位。
- 原生落地时 Android 在现有 `PimTheme`/平台主题和可组合组件中定义；Windows 使用主题资源字典及共享样式引用，需随主题变化的值采用动态资源；Web 使用主题变量和基础组件。共享语义和规范，不强迫三端共用不适配平台的一份 UI 代码。
- 代码评审检查业务页面没有新增绕过主题的颜色或重复基础控件样式；验证修改一个主题资源能同步影响多个使用处。前期样板验证与当前安卓主题组件验证分别记录，不代表各客户端或原生笔记页面已全部完成资源化改造。

## 4. 首批组件边界

| 组件/模式 | 本轮样板覆盖 | 原生实施边界 |
| --- | --- | --- |
| 主题与文档页壳 | 共享主题引用、手机/平板结构、中文长文、内容导航；无品牌栏，右上角悬浮结束 | 演进现有 `PimTheme`，不新增互不相认的主题；Windows 复用资源字典，基础组件共同维护，按批次接入 |
| 紧凑录音条 | 左下角、段号/时长/波形示意、暂停和自动续段状态 | 波形必须接真实采集信号；采集/计时/落盘不依赖该控件存活 |
| 手写卡片框架 | 右下角双维拖拽、键盘微调、宽度约束；示意笔迹不随外框拉伸 | 尚无真实笔迹编辑引擎；必须验证成熟方案、笔/掌触/正文滚动与持久化 |
| 材料入口 | 右下角插入菜单、照片示意；宽屏材料入口 | 接真实相机、权限及本地附件关联，不把示意图当拍照完成 |
| 处理状态与版本提示 | 离线、处理中、部分失败、原稿改动、人工修订和冲突保全样板 | 按真实数据展示；固定版本、幂等、长附件、任务与故障处理仍需实现 |
| 结果阅读与修订 | 原稿/逐段文字/完整记录/分析分开；可修订示意结果，更新时保留人工稿 | 当前只是浏览器内交互，不是成熟 Markdown/混合文档编辑器或服务端历史版本支持 |

按钮、输入框、对话框等优先主题化平台组件，不先重写通用控件库。新的可复用抽象从真实功能提炼，手写和云处理不得借组件建设再次移出首版。

## 5. 前期样板产出与验证边界

- 已新增两套关键页视觉样板，支持手机/安卓平板布局、原稿/逐段文字/完整记录/分析，以及十类状态检查；不是完整应用导航或全量迁移页面。
- 样板素材为合成课堂内容，没有使用用户研究截图、录音或私人笔记，也不调用麦克风、相机、上传、ASR 或模型。
- 本次另建视觉样板，不替换此前 `pim-notes-flow.html` 的流程草图。两者都不是原生实现，原型状态名不是 API 状态机。
- 设计选项及页面/尺寸等交互偏好可回显；正文及人工修订仅在当前样板内暂存，不进入供模型读取的状态，不当作正式笔记存储。
- 浏览器检查记录与截图保存在本地 `.codex-tmp/native-notes-visual-20261025/`。两种方向、手机/平板、320/360/736 像素宽度、深浅外观及十类状态共 240 个组合通过布局检查，另检查 20 像素正文；未发现横向外溢、正文截断或脚本运行错误。
- 已检查鼠标及触控仿真的右下角双维拖拽、键盘微调、44 像素手柄、拖拽后的首次点击，以及暂停、结束/取消、离线提交、补录、部分失败重试、人工修订保全和冲突双稿。四种方向/主题组合的正文、次要文字和主按钮对比度均不低于 4.5:1；已查看七张关键场景截图。
- v0.2 重新通过上述 240 个组合，确认没有常驻品牌行，右上角按钮与标题不重叠并保留至少 44 像素触控高度；结束确认和补录仍可用。另实际替换主色、控件圆角、触控目标和辅助字号各一处资源，验证两种布局的多个使用处随之改变，再恢复正常主题。
- 以上仅为浏览器样板检查，不代替 Android 真机、系统字号/键盘、真实笔输入、后台录音或云端链路验收。

## 6. 下一步退出条件

蓝色基调和关键操作位置已确认，按此收敛必要参数后即进入真实安卓切片，不等待所有模块页面或大型组件库。主题与基础组件引用是实施约束，不另行扩张成设计系统平台；原生录音/恢复及编辑器风险验证可以与外观细化同步推进，关键页可读可操作不等于后台录音已验收。

仓库实施读取适用 `AGENTS.md`，保护现有改动，从最新 `origin/master` 建立非 master 分支并按 PR 规则交付。本文与总路线图通过 PR 纳入正式文档并建立入口链接，避免仅保留在聊天和本地草案中。

## 7. 安卓首批实现边界

- 在现有主应用 `ui/theme/` 内统一颜色、排版、形状和尺寸，仍通过原有 `PimTheme` 入口提供；业务页面不另起主题。品牌主色保持 `#1D63D8`，各 Material 语义角色明确映射，避免未覆盖角色退回默认紫色。
- 成功和警告增加语义资源，与信息/错误主题角色一起供共用状态提示使用；今日的事实标签、设置等处的 `PimSection`、今日/嵌入页的按钮和未加密连接提示实际复用这些定义。
- 原生按钮沿用 Material 交互/禁用语义并统一最小触控高度；没有新造一整套输入、弹窗、导航控件。尚未出现的笔记业务组件随真实切片提炼，不先加入有假录音状态的发布页面。
- 浅色仍是现有默认，深色资源可显式用于组件验证；这不是新交付的全应用深色设置，也没有验证嵌入 Web 页面自动适配深色。
- 本批没有新增笔记列表/混合编辑器、麦克风服务、手写引擎、上传或 ASR/AI。首版手写及其他平台目标继续保留；主题测试不能填作后台录音或 OPPO 真机验收证据。
