# PIM 视觉基础与笔记样板

版本：v0.4 离线正文主题与可用素材决议稿。日期：2026-10-26。

用户已同意“先薄视觉基础和关键页样板，随后立即进入真实功能”的方法，并明确延续 PIM 蓝色基调、取消常驻“PIM 笔记”品牌栏、将结束操作放在右上角悬浮，以及颜色和基础组件一处定义、多处引用。用户已确认外观足够，先统一后继续，不再扩展大批静态样板。其余细节在真实切片中完善，业务规则与稳定需求编号仍以 [PIM原生客户端与笔记路线图](native-notes-roadmap.md) 为准。

2026-10-26 用户接受“原生宿主 + 离线成熟开源正文核心”的方向，并确认参考包中的动画和字体可用。当前仍暂停功能开发，只确定主题桥接与素材利用规则；可用不等于已经选中、打包或完成适配，不因此照搬 OPPO 品牌。

## 1. 设计原则

- 整个 PIM 共享产品识别与视觉语义，首先用笔记证明可用，不提前设计全部日历/任务等页面。
- 延续原生客户端已有蓝色方向，已获用户确认；正文阅读与书写优先，主操作不靠大面积色块抢占编辑区。
- 页首直接呈现笔记标题与保存状态，不再常驻“PIM 笔记”品牌栏；“结束”作为应用内右上角轻量悬浮操作，与标题留出避让空间，不另占整行。结束确认和后续补录规则不变，不是跨应用悬浮窗。
- 所有颜色从统一主题的语义资源引用；按钮、输入区、状态提示等基础组件只维护共同定义和必要变体，不在业务页面复制样式。
- 录音条保持应用内左下角紧凑悬浮；手写卡片内嵌正文，右下角直接拖动宽高。位置和交互是已确认规则，不参与本轮外观方案的重新投票。
- 状态用文字与结构表达，颜色仅辅助；录音、暂停、保存、上传、AI 完成、中断和冲突不得混淆。
- 手机、平板按实际可用空间重排，不按 OPPO 型号写死尺寸，不把平板当成放大的手机，也不把同一布局强行缩小。

## 2. 阅读布局参考

| 方向 | 排版与布局 | 交互差别 | 当前定位 |
| --- | --- | --- | --- |
| 清晰文档 | 蓝色克制强调、干净文档底色、无衬线标题、下划线内容导航；宽屏时左侧展示本篇录音/手写/照片材料 | 平板从材料侧栏直接进入对应内容；手机保留单列正文 | 保留布局对照，不据此继续扩大静态样板 |
| 安静纸面 | 同一蓝色产品识别，偏暖纸面、中式衬线标题、独立文档页、分段式内容导航；宽屏正文居中并增加页边距 | 材料入口收在原稿和插入操作中，结果按阅读稿组织，不常驻材料侧栏 | 最近样板偏好，作为阅读布局参考；不把所有字体和平台数值视为冻结 |

两者不是仅换颜色：页面结构、宽屏空间分配、材料访问方式、标题及内容导航均有差别。蓝色基调、取消品牌栏、右上角结束、左下角录音及手写拖拽行为共同生效，不再作为待确认项；不能把这些确认扩大为所有字体、主题范围和布局细节已冻结。

- 深浅样板检查不等于现有全应用已经支持暗色。最终主题交付范围、字体适配与无障碍需进入真实客户端核验；参考包字体/动画的可用确认已记录于第 3.2 节，不再列为许可待确认。

### 3.1 一处定义、多处引用的实现约束

- 主题入口集中定义颜色资源，业务页面只引用 `Primary`、`OnPrimary`、`Surface`、`Text`、`TextMuted`、`Border`、`Success`、`Warning`、`Error` 等语义，不直接散写色号。浅深色映射集中维护，不能靠逐页替换蓝色色号调整产品基调。
- 字体层级、常用间距、圆角、触控目标和浮层阴影使用命名资源；按钮、图标按钮、输入区、材料边界、状态提示和确认框共享基础定义及明确变体。页面负责组合和行为，不复制一份控件再单独调样式。
- 样板已将颜色集中在根级主题资源中，通过引用供两种布局使用；基础按钮、输入区和材料边界使用共同样式，浮动结束按钮复用主按钮而非另造一套。用户拖出的卡片尺寸、波形样本和按空间计算的布局是运行数据，不要因此变成固定尺寸档位。
- 原生落地时 Android 在现有 `PimTheme`/平台主题和可组合组件中定义；Windows 使用主题资源字典及共享样式引用，需随主题变化的值采用动态资源；Web 使用主题变量和基础组件。共享语义和规范，不强迫三端共用不适配平台的一份 UI 代码。
- 离线正文核心通过受控主题数据映射到 CSS 变量/编辑器样式，复用同一组语义色、字体层级、字号缩放、间距及外观状态；不从 OPPO 混淆 bundle 提取主题桥接代码，也不在正文内再写一套品牌常量。主题变化不能重建原稿、清空撤销或中断录音。
- 代码评审检查业务页面没有新增绕过主题的颜色或重复基础控件样式；验证修改一个主题资源能同步影响多个使用处。前期样板验证与当前安卓主题组件验证分别记录，不代表各客户端或原生笔记页面已全部完成资源化改造。

## 6. 下一步退出条件

当前功能开发暂停；以下为恢复后的实施约束，不据此立即替换正文引擎或复制素材。

蓝色基调和关键操作位置已确认，按此收敛必要参数后即进入真实安卓切片，不等待所有模块页面或大型组件库。主题与基础组件引用是实施约束，不另行扩张成设计系统平台；原生录音/恢复及编辑器风险验证可以与外观细化同步推进，关键页可读可操作不等于后台录音已验收。
