# 文件系统的内置存储

内置存储是 `IFileProvider` 的 `local` 实现，显示为“内置存储（服务器）”。它使用 PIM 服务器的持久磁盘，不是浏览器缓存或手机目录，也不要求先绑定云盘。笔记全量目标仍由[总路线图](../product/native-notes-roadmap.md)维护。

## 默认来源与兼容

- 首次列出来源或首次存附件时，为当前登录用户幂等创建一个来源和根目录。无 OAuth、无伪造 refresh token；独立数据库上下文避免把调用方未提交的业务实体一起保存。
- 已有显式默认来源保持不变；未设置时优先沿用最早连接的云盘，只有没有可用云盘时才使用内置存储。显式默认或网页记住的来源失效时提示用户重连或手动切换，不静默改写上传位置。
- 文件页可以切换来源及“设为附件默认”。切换浏览来源不等于修改附件默认。内置来源不能断开；旧 OneDrive/Google 文件与附件引用不迁移、不改写。
- 未带 `providerId` 的旧列表调用，仍按唯一云盘兼容；无云盘时选内置来源，多个云盘仍要求明确来源。新客户端应始终传明确的 `providerId`。

## 数据与权限

虚拟目录、文件名、回收站和上传会话关联保存在每用户目录中的原子 JSON 目录；业务数据库保留既有文件索引/附件引用。普通文件通过内容摘要定位；用户文件名不参与物理路径。支持目录、上传、下载、文本读写/快照、改名、移动、删除/恢复与全量索引同步。暂不支持对外分享或云盘网页入口，网页隐藏相应文件操作。

下载/预览链接是五分钟、用途隔离的 Data Protection 授权，绑定用户、来源、文件、路径和内容版本。生成链接要求已有登录及归属/敏感路径检查；兑现链接再次核对来源、实时目录和敏感路径。改名、移动、删除或改变内容后旧链接失效。字节端点不接收通用账号凭据，临时链接不可视作永久附件地址。图片/PDF/纯文本可安全预览，HTML/SVG 不作为活动内容内嵌；响应设置 `nosniff`、禁止引用传递与私有不缓存。分享链接并未由此实现。

文件会话上传复用现有开始/完成接口及 `Content-Range`、202 `nextExpectedRanges`、200 `id` 协议。已经确认的重叠字节必须一致；完成后同一会话的相同重试返回同一条目，不同内容拒绝。完成哈希先进入会话日志，再把暂存文件封存到普通文件命名空间，避免发布时复制一份同样的大文件。父目录或同名冲突会明确拒绝，保留暂存/封存字节；不静默覆盖已有文件。

## 统一字节层与笔记

`ManagedBinaryStore` 为普通文件、可变暂存上传和不可变笔记材料分块提供同一底层，分别使用 `files`、`file-uploads`、`note-parts` 命名空间。账号、集合和对象标识均由服务端生成并检查；拒绝已发现的链接/重解析路径。目录事务和字节事务分别使用磁盘锁；部署文件系统必须支持文件锁及原子替换。

笔记的版本清单、同意、冲突指针和删除语义仍属于笔记层。新收材料写到共享字节层；旧 `NativeNotes:StorageRoot` 中的分块仍可读取与删除，不要求立即迁移。笔记材料没有作为普通可删除文件暴露，普通文件清理也不能删除笔记版本字节。详见[笔记收包说明](native-notes-material-upload.md)。这没有接通 Android 上传、ASR 或 AI。

## 配额、部署和未完成项

| 边界 | 当前默认/限制 | 说明 |
| --- | --- | --- |
| `ManagedStorage:Root` | Linux `/data/pim/storage`；Windows 当前服务账号 LocalAppData 下 `PIM/server/storage` | 必须是绝对路径；现有容器 `/data` 持久卷覆盖默认目录 |
| `ManagedStorage:MaxUserBytes` | 20 GiB | 普通文件、历史不可变对象、暂存文件与新笔记分块共享；不包含旧笔记目录和元数据 |
| `ManagedStorage:MaxUserObjects` | 100,000 | 共享字节对象数量；虚拟目录另有 100,000 条目限制 |
| 单普通文件 | 2 GiB | 每次会话分块最多 10 MiB；不是一篇笔记或多段累计录音上限 |
| 普通小上传/旧附件门面 | 4 MiB | 超过该值的普通文件走会话；原生笔记走独立 1 MiB 分块收包 |
| 普通上传有效期 | 24 小时 | 每用户最多 10 个未完成会话；下一次创建会话时清理到期暂存和状态 |
| 笔记版本额度 | 继续使用 `NativeNotes:*` | 先检查笔记预留额度，写入时还受共享字节额度约束；不足时保留已收块与本机原稿 |

删除普通文件当前进入回收站；旧内容对象和失去目录引用的封存字节尚无物理垃圾回收，仍计入共享容量。会话过期清理不是后台定时扫描。尚无全服务器总配额、容量管理界面、存储在线迁移或自动备份删除。不要向用户承诺删除即可立即回收空间。

存储卷、数据库索引、Data Protection 密钥和笔记账本均需按部署策略备份；更换授权密钥会影响短链接，丢失数据卷不能靠文件索引重建内容。真实磁盘耗尽/掉电、网络文件系统、多节点部署与生产备份恢复未验收。当前证据是隔离数据库/临时目录中的真实 HTTP/磁盘测试和合成接口的浏览器操作，不代表真实云盘、OPPO 或生产部署验收。
