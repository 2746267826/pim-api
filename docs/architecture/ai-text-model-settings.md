# SDK 文字模型设置与完整调用记录

核对日期：2026-10-29。本文记录已合并PR #514的文字基线；新增视觉能力见[多图说明](ai-vision-calls.md)，持久分段与普通账号授权见[ASR任务说明](native-note-asr-tasks.md)。该文字切片实现管理员 Web 设置到一次非流式文字调用、实际内容记录和统计的完整路径。合并与构建状态以关联 PR 的当前 head CI Gate 为准；#520固定材料持久分段任务与#528普通账号ASR API已合并，但不代表本文文字基线、完整记录或完整MVP已完成。总范围继续引用[唯一总路线图](../product/native-notes-roadmap.md)。

## 使用方式

管理员进入“设置 → AI 设置”（`/settings/ai`）。添加模型的名称、实际 API 根地址、模型标识与 API Key，可声明文本、视觉、语音转写中的多种能力，并分别选择默认模型。当前扩展已支持PNG/JPEG多图视觉；ASR已在[独立预设切片](ai-asr-presets.md)接入MiMo单片，#520持久分段任务和#528普通账号授权/destinations已合并。本文文字基线本身仍不包含长材料步骤；完整记录/独立分析/修订保护未完成。类型选择不证明供应商实际支持，需对应验证。

选择默认文本模型并启用“SDK 直连”，填写可选系统提示与正文/上下文，点击“发送并记录”。正文按输入保留换行与空白；页面可查看实际回复，再打开完整记录。切到“调用记录”或“统计”不会取消正在等待的调用；离开本页或点击“取消等待”会请求取消，之后先核对记录。每次明确新建调用可能产生新的供应商费用。

“调用记录”支持分页、状态与模型标识筛选，详情包含实际请求消息、回复、SDK 请求/响应正文、模型地址与配置版本、结束原因、用量和错误。“统计”显示记录数、已结束记录成功率、服务商上报的输入/输出/总 Token、平均耗时及按模型分组。进行中不当成失败；未上报用量和费用明确为未知，不估算价格或跨币种相加。记录数包含未执行的受阻记录，并非供应商收费次数。

配置和全部调用历史沿用现有管理员权限；普通用户不能调用这些管理接口。配置是系统级，调用记录保留发起用户；按客户端请求标识核对结果时仅能查询本账号的记录。停用默认模型后仍可关闭 SDK 总开关并保留默认引用，再启用前须恢复/切换模型。其他业务后续通过自身授权接入，不直接开放管理员控制台。

## 组件与兼容边界

- 复用现有 `Microsoft.Extensions.AI.OpenAI` 10.6.0、`OpenAI` 2.10.0、`System.ClientModel` 1.10.0 解析组合，未新增运行时或代理依赖。`ChatClient.AsIChatClient()` 负责协议生成和结果解析；PIM 只绑定配置、权限与审计。
- 当前走 OpenAI-compatible **Chat Completions 非流式文本**。根地址按实际服务填写，例如包含供应商要求的 `/v1` 或自定义前缀；PIM 只规范末尾 `/`，不自动补 `/v1`。这是 PIM 服务器访问的地址，不是浏览器或手机的回环地址。禁止地址内的账号密码、查询参数、fragment 和保存的凭据；不跟随 HTTP 重定向。
- SDK 通用重试为 0，单个逻辑请求最多一次 SDK 传输尝试。429、5xx、鉴权或格式错误不会自动重复计费，也不静默回退模型。未来结构修复/业务重试必须另立明确预算，不能与旧循环相乘。
- 旧 `AiGateway`、环境 `Ai:Enabled`、旧健康检查和 LiteLLM 部署保留。新“SDK 直连”开关控制新控制台，旧业务不会自动迁往新默认模型；旧、新记录可统一查询。完成旧调用方兼容回归后才清理 LiteLLM。
- 当前新建配置要求非空 API Key；无认证的本地兼容服务需填非秘密占位值，尚无单独的无认证模式。类型复选框是管理员声明，不执行自动能力探测。

## 数据、凭据与版本

EF 迁移 `20261027031046_AddAiModelProfiles` 新增 `ai_model_profiles`、`ai_model_runtime`，为既有 `ai_request_logs` 添加可空的关联、结束原因、脱敏和执行期限字段。旧历史继续可读；删除配置不删除历史，正在使用的默认配置需先切换/清空。配置及默认选择采用 revision 乐观并发；过期编辑返回 409，界面保留草稿供核对。

API Key 通过现有 `ISecretProtector` / ASP.NET Core Data Protection 加密保存。列表只返回 `hasApiKey`；编辑不回显，`apiKey: null` 保留原密钥。表单关闭/保存后清空，不写浏览器持久缓存。部署须保留既有 `DataProtection:KeysPath` 密钥环，备份/恢复应与数据库配套；丢失密钥时需重新保存配置，不能声称只恢复数据库即可恢复凭据。

每次调用固定模型 ID、配置 revision、名称、地址及实际消息；执行期间修改默认模型或删除配置不改变本次输入。审计处理器只捕获 SDK 的请求/响应正文，不捕获认证头，不自行实现供应商协议。普通业务文本如 `password=...` 原样保留；内容若恰好包含本次配置的认证密钥则遮盖，并设置 `contentRedacted`。受控调用记录保留实际内容，普通运行日志不重复打印提示词、回复或密钥。

## 幂等、故障与实际限制

1. 浏览器为一次操作生成 `clientRequestId`，携带当前 `expectedUserId`；会话变化直接拒绝，防止重新登录后把旧输入发送为另一个账号。数据库对用户/请求标识建唯一索引；同 ID 同输入返回已有记录，变更输入返回 409，均不重新调用。完成后需明确“新建一次调用”才能产生新请求。
2. 调用外部服务前先持久保存 running 记录。取消、超时、HTTP 错误、解析错误、内容过滤、工具调用、长度截断或无普通文本回复均有不同状态/原因；仅正常 stop 且存在文本才算成功。即使 SDK 无法解析，完整收到的错误/非 JSON 正文仍可查看；非 JSON 用 JSON 字段包装保存。
3. 浏览器结果不确定时通过 GET 核对，不重发模型调用。记录超过“开始时间 + 本次超时 + 60 秒”仍为 running，在下一次记录/详情/统计/核对或现有质量巡检访问时转为“未完整/结果未确认”，不重执行。巡检同时识别 `succeeded` 与旧 `Success`，排除仍在执行的记录，且只读取状态/错误字段，不批量加载完整提示词与回复。当前不是后台持久工作队列，也不保证外部供应商已停止或免除费用。
4. 外部服务与数据库不能原子提交。如果模型已执行但结果写入失败，返回 503 提示先核对、不要自动重发；原 pending 记录可最终标未知，**不能保证恢复从未成功写库的回复**。笔记长任务将在既有 Hangfire 中另做步骤/材料版本保护。

| 限制 | 当前实现与不足 |
| --- | --- |
| 输入 | PIM HTTP 正文上限 1 MiB；系统提示最多 32,000 字符，合计最多 200,000 字符；SDK 实际请求正文缓冲最多 2 MiB。超限明确拒绝，不静默裁剪 |
| 响应 | 解压后非流式响应正文最多 4 MiB；超过即失败并标记，不假称完整保存。传输中断前尚未收全的部分正文没有恢复界面；流式/部分回复留存仍待下批 |
| 时限与输出 | 每模型 1～600 秒，最大输出 1～131,072 Token；实际支持范围取决于供应商，不承诺任何兼容模型都接受所填值 |
| 并发与数量 | 每服务进程最多 4 次并发；创建时检查最多 64 个配置。尚非分布式全局配额或跨实例严格数量限制 |
| 统计 | 当前展示全历史及按模型标识汇总；调用列表支持分页/状态/模型筛选。时间范围 UI、更多维度、计价表、保留期与清理操作未接入，不把未知费用当零 |
| 业务 | 文字基线不含Responses、工具执行、流式、ASR、长材料步骤、人工稿保护和安卓UI；图片输入已在独立视觉切片补齐，具体限制见其说明 |
